# Game-001-Art

Game-001のアート素材を管理するリポジトリです。

## 管理対象

- 3Dモデル
- テクスチャ
- マテリアル
- アニメーション
- VFX素材
- UI素材
- アート制作元データ

## ディレクトリ構成（予定）

- SourceAssets/：編集用の制作元データ
- RuntimeAssets/：ゲームで使用する出力済み素材
- Documentation/：制作規約と素材情報

## 運用方針

大容量バイナリファイルはGit LFSで管理します。

Git LFS設定が完了するまでは、大容量素材を登録しないでください。

## 管理担当

Game-001-Artists

## 開発状況

開発基盤構築中。

## 利用方法

- 作業は `main` からブランチを作成し、Pull Requestで提案してください。
- タスクはGitHub Issues / Projectsで管理します。
- 変更の責務: Game-001-Art。担当Team: `Game-001-Artists`。
- 依存関係や開発状況は [DevelopmentDocs](https://github.com/FUREQ-DEVELOP/DevelopmentDocs) を参照してください。
